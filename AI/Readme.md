# AI

Owner: Shashi

## Build
- Speech to text for Hindi and English (Whisper or browser speech API)
- LLM that turns a spoken or typed request into JSON: blood group, units, hospital, urgency
- Mapper from free-text disease entries to the rule categories used by Backend
- Plain-language reasons for "not eligible" results
- Detection of duplicate or suspicious requests

## Rule
The AI never decides eligibility. The Backend rules engine decides.
