# Frontend

Owner: Payal

## Build
- Donor sign-up and health form (all fields required)
- Donor result screen: Eligible / Not eligible with reason / Eligible after a date
- Receiver login and request screen with a mic button and text box
- Request status screen: live timer, current radius, accepted donors
- Donor alert screen with Accept button and countdown
- Map of donors and hospital (Leaflet + OpenStreetMap)

## Suggested stack
React or Next.js, mobile-first, Leaflet.
